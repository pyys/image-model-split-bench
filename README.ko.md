# image-model-split-bench

**이미지 생성 모델을 여러 GPU 에 쪼개는 비용 — 실측.**

이미지 생성 모델은 VRAM 이 모자랄 때 다중 GPU 보다 양자화나 파라미터 수가 작은
모델로 대응하는 경우가 더 많다. 이미지 생성 모델에서 다중 GPU 가 비효율적이라는
통념 때문이다. **이 저장소는 그 통념을 실측으로 검증한다.**

이미지 모델의 구성 모듈 중 가장 큰 DiT 를 **레이어 분할과 텐서(row) 분할**로 여러
GPU 에 나눠 적재하고, **같은 카드를 독립 워커로 쓰는 구성**과 나란히 비교했다.
FLUX.1-dev 파생 DiT 의 Q4_0 양자화본, 512×512 / 15스텝 고정. 플랫폼은
P104-100 ×4(PCIe Gen1 x4)와 V100 16GB ×4(PCIe Gen3 x16)이다.

**DiT 를 여러 GPU 에 나누면 느려졌다.** 카드 4장으로 1장의 **84~87%**(레이어 분할),
**15~16%**(텐서 분할)다. 레이어보다 텐서 분할에서 저하가 훨씬 컸다. 반면 **같은
4장을 독립 워커로 쓰면 344~388%** 였다. 두 플랫폼은 인터커넥트 대역폭이 **16배**
차이 나는데 텐서 분할의 저하는 줄지 않았다.

**따라서 저하의 원인은 인터커넥트 대역폭이 아니며, 통념은 모듈 분할에만
해당한다.** 이미지 생성에서 다중 GPU 로 산출 속도를 올리려면 **모듈을 쪼개지 말고
복제하는 방향**으로 설계해야 한다.
